# DataTable

Общая таблица получает `rows`, `columns`, `rowKey` и доступное имя `caption`.
Она отвечает за компактные строки, границы, прокрутку, закреплённые заголовки
и колонки. Данные, фильтры, сортировка, пагинация и запросы принадлежат модулю.

`DataTableColumn<TKey>` описывает стабильный `key`, `label`, `width` в пикселях,
необязательные `align` и `pinned: "start" | "end"`. Ширины задаются явно;
широкая таблица прокручивается внутри своей области, не расширяя страницу.
Одна незакреплённая колонка с `grow: true` заполняет свободную ширину;
по умолчанию это первая незакреплённая колонка. Закреплённые колонки сохраняют
точную ширину, поэтому их смещения остаются правильными на широком экране.

Типизированный слот `cell` получает `{ row, column }`; необязательный `header`
получает `{ column }`. Через них модуль добавляет ссылки, статусы, изображения,
меню и checkbox. Таблица не интерпретирует названия полей и не вызывает API.

Для выбора строк передайте `selectedKeys`; checkbox и обработчики выбора
остаются у владельца данных. `density="compact"` включает строки высотой 32 px,
по умолчанию — 40 px. Событие `rowActivate` сообщает о двойном клике;
основное действие строки также должно быть доступно кнопкой или ссылкой.

Загрузка, ошибка с повтором и пустой результат отображаются компонентом Body
модуля. Примеры подключения: `CatalogItemsTable.vue` и `CompaniesExampleTable.vue`.
