# Reference Data

`reference_data` владеет четырьмя глобальными справочниками в `public`: страны,
валюты, локали и временные зоны. Это read-only данные для бизнес-модулей и HTTP
клиентов. Их обновляет только внутренний сценарий синхронизации; tenant не создаёт
и не изменяет записи глобального справочника.

## Источники и формат

| Справочник | Стандарт и источник | Ключ |
| --- | --- | --- |
| Страны | ISO 3166-1 через Unicode CLDR code mappings | `UA` |
| Валюты | ISO 4217, официальный XML List One SIX | `UAH` |
| Локали | BCP 47 и Unicode CLDR, включая `uk-UA` и `ru-UA` | `uk-UA` |
| Временные зоны | IANA tzdb `zone1970.tab` и `zone.tab` | `Europe/Kyiv` |

Коды являются первичными ключами. Исчезнувший из источника код остаётся в базе с
`active=false`. Новые HTTP-списки показывают только активные коды. Текущее UTC
смещение зоны не хранится: оно зависит от даты и правил tzdb. Связь страны и
временной зоны лежит в `ref_country_time_zones`.

CLDR и IANA загружаются из опубликованных HTTPS-ресурсов, SIX — из официального
XML. Модуль не вызывает источники в пользовательском HTTP-запросе. Каждый источник
реализует Application-порт; синхронизация проверяет полноту, ключи и обязательные
значения перед записью. Запись одного набора и его `ref_sync_state` проходит в
общем UoW. Сбой оставляет предыдущую успешную версию.

## HTTP

Аутентифицированный участник tenant может читать:

```text
GET /api/console/reference-data/countries
GET /api/console/reference-data/currencies
GET /api/console/reference-data/locales
GET /api/console/reference-data/time-zones
```

Списки отсортированы по коду. Маршрутов записи нет. У локали `region_code`
содержит региональный подтег (`UA`, `XK`, `419`) либо `null`, если региона нет.
`country_code` — отдельная необязательная ссылка на ISO-страну: у `sr-Cyrl-XK`
регион равен `XK`, а `country_code` равен `null`. Для списка кодов контента без
региона следует проверять `region_code IS NULL`, а не `country_code IS NULL`.
Наличие локали в справочнике не означает наличие готового перевода интерфейса.
Коды валют остаются глобальными: `USD` и `EUR` доступны в справочнике независимо
от выбранной страны.

## Развёртывание и обновление

После миграции `0006_reference_data` выполнить первоначальную загрузку до открытия
новых GET-маршрутов:

```sh
dnk-manage database upgrade
dnk-manage reference-data sync --dataset all
```

Команда повторяемая; отдельный набор обновляется через `--dataset countries`,
`currencies`, `locales` или `time-zones`. Worker общих scheduled jobs автоматически
регистрирует глобальное задание на каждый набор раз в семь дней: понедельник
03:00 UTC. `tenant_id=NULL` означает глобальное задание; TenantGate применяется
только к tenant-заданиям. Идентификатор задания зависит от набора и недельного
интервала, поэтому несколько worker не добавляют дубликаты.

Глобальный справочник содержит возможные коды, но не выбирает их за tenant.
Настройки языков контента принадлежат Catalog; настройки локали публикации — Channels.
Tenancy не хранит отдельный список разрешённых локалей.
