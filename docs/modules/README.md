# Modules Docs

Этот каталог содержит краткую инженерную документацию по текущим модулям проекта.

Файлы:

- `config.md` — конфигурация и источники настроек
- `shared.md` — общие технические механизмы
- `mock.md` — mock endpoints и frontend bootstrap contracts
- `tenancy.md` — tenant/domain bounded context
- `identity.md` — user/email/auth bounded context
- `crm.md` — текущее состояние модуля CRM
- `catalog.md` — текущее состояние модуля Catalog
- `org.md` — текущее состояние модуля Org

Документация ориентирована на разработчиков и описывает:

- ответственность модуля
- основные директории
- use cases и контракты
- порты и adapters
- текущие ограничения и точки расширения
