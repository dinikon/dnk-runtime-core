# Согласованный дизайн CORE

Утверждённые изображения служат визуальным ориентиром, а не источником данных:
[главная](home.png), [вход](login.png), [безопасность](security.png),
[формы и мобильные состояния](forms.png).

Реализация использует Inter, нейтральную светлую тему, тонкие границы,
чёрные основные кнопки, радиус 8 px и элементы управления от 44 px.
Провайдеры и сведения аккаунта зависят от конфигурации и текущего пользователя.
Вместо вымышленных статусов из изображения показываются реальные значения.

Визуальная проверка сравнивает заголовок/ширину Hero, действия и блок возможностей,
открытую форму входа, подписи/ошибки/размеры полей, боковую навигацию,
строки настроек и мобильное раскрываемое меню. Формы сохраняют серверный HTML
при недоступном JavaScript. Runtime-консоль и внутренний admin не изменяются.
