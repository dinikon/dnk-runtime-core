# Prom: текстовый XML с сохранением категории, 20 октября 2026

Разрешённая владельцем карточка: native ID `3240302692`, ключ файла
`dnk-xlsx-probe-3240302692`. Файл
[13-existing-texts-with-category.xml](13-existing-texts-with-category.xml)
содержит только RU/UK название и описание, а также текущий
`portal_category_id=1333`. Группа, цена, скидка, наличие и SKU в XML отсутствуют.

Параметры: `force_update=true`, `only_available=false`,
`mark_missing_product_as=none`, плоский
`updated_fields=[name,description,name_ua,description_ua]`.
Ключ `<offer id>` — API `external_id`, а не native ID карточки.

Файл на сервере владельца проверен побайтово. Прямой `/products/import_file`
принял запрос с ID `6ad7c3a950712db41db1e608`. В течение первых десяти минут
API показывал `SUCCESS`, но `total=0` и прежние тексты. После подтверждения
владельцем завершения импорта повторное чтение исходного native ID подтвердило
все четыре новых текста. Это важное ограничение наблюдения: HTTP 200, `SUCCESS`
и нулевые счётчики сами по себе не доказывают выполнение.

По полному сравнению before/after изменились только `name`, `name_multilang`,
`description`, `description_multilang`. Группа, категория, цена, скидка, валюта,
SKU, наличие, количество и изображения сохранены. Тестовая карточка не имела
реальных изображений: для непустой галереи есть отдельная контрактная fixture,
живой тест не подтверждает поведение всех возможных карточек Prom.
Все остальные 26 карточек кабинета не изменились, новых native ID нет.

Исходно скрытый товар был временно опубликован для проверки поддержанного
срезом статуса. После фактического завершения импорта восстановлен
`status=not_on_display`; наличие осталось `available`. Промежуточное скрытие
до окончания импорта оказалось недостаточным: поздняя обработка снова
показала товар. Поэтому скрытые позиции в MVP исключаются из отправки.

`/products/import_url` отклонил одну попытку HTTP 400 из-за занятого импорта;
import ID не был выдан. Повторная попытка была остановлена до отправки при
проверке изменившейся видимости. Успешного живого `import_url` этого файла в
этом эксперименте нет. Сквозную проверку публичного endpoint приложения
владелец отложил до публикации. API, подписанный URL, чтение настоящего файла
из приватного MinIO, XML и фоновые шаги проверяются вместе на изолированной
площадке fixture в PostgreSQL-тестах.

XML-импорт остаётся upsert. Предварительный полный обход ключей уменьшает риск
непреднамеренного создания, но не устраняет удаление/смену ID между проверкой
и обработкой файла. Ядро не обещает `update-only`, не меняет привязку на новый
native ID и подтверждает результат чтением исходных карточек.

Обезличенный результат: [results.json](results.json). Закрытые полные снимки
и credentials в репозитории не сохраняются.

Контракт: [официальное описание YML/XML Prom](https://support.prom.ua/hc/uk/articles/360004963538),
[Swagger API](https://prom.ua/cloud-cgi/static/uaprom-static/docs/swagger/index.html).
