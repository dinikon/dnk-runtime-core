# Develop Style

This page is a lightweight companion to the project documentation and points to the current architecture and
documentation conventions used in the codebase.

## Current Focus

- clear bounded contexts
- thin orchestration use cases
- explicit dependency composition
- session-bound repositories and adapters
- one active `UnitOfWork` per request or management command
