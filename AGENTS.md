## Обязательное соблюдение архитектуры модулей

Перед созданием или изменением backend-модуля прочитай
docs/architecture/AGENTS.md и составь перечень применимых требований.
Если вывод файла обрезан, дочитай оставшиеся части отдельными запросами.
Не считай чтение примеров заменой чтения нормативных правил.

Архитектурный документ является обязательным источником требований.
Существующий код служит примером только там, где не противоречит документу.

Перед реализацией:
1. Определи Aggregate Roots и правильную структуру слоёв.
2. Перечисли use cases, их входы, результаты и необходимые файлы:
   command/query, handler, dto, ports, adapters, HTTP-контракты, Depends.
3. Для каждого результата определи конкретный DTO и возвращаемый тип.
   Для операции без результата используй -> None; пустой DTO не нужен.
4. Проверь дополнительные требования документа, а не только этот список.

Обязательные проверки реализации:
- Все методы имеют аннотации параметров и возвращаемого значения,
  включая __init__ -> None и Handler.execute.
- DTO принадлежат конкретным сценариям; универсальный DTO не заменяет
  отдельные контракты разных use cases.
- __post_init__ разрешён только в Value Objects.
- Aggregate и Entity используют явные фабрики create/restore;
  изменения состояния выполняются через доменные методы.
- Инварианты агрегата не переносятся в persistence mapper или VO
  ради обхода требований.
- Соблюдены направление импортов, границы слоёв и транзакций.
- HTTP Request/Response разделены согласно архитектурному документу.
- Выполнены требования к именованию, расположению файлов и docstrings.

Перед завершением:
1. Проверь весь diff по перечню применимых архитектурных требований.
2. Проверь наличие обязательных файлов для каждого use case.
3. Выполни необходимые тесты и статические проверки.
4. Исправь найденные нарушения до итогового ответа.

Успешные функциональные тесты не доказывают соблюдение архитектуры.
Не объявляй работу завершённой при известных нарушениях.
В итоговом ответе укажи выполненные проверки и оставшиеся ограничения.
