# Архитектурные правила

Перед изменениями выбери обязательные правила по области задачи:

- Backend, серверные API, БД и соответствующие тесты/документация:
  [docs/architecture/backend.md](docs/architecture/backend.md).
- Frontend, клиентские API, UI, состояния и соответствующие тесты/документация:
  [docs/architecture/frontend.md](docs/architecture/frontend.md).

Загружай только правила затронутой части; для задачи на стыке backend и frontend
прочитай оба файла. Читай выбранный документ полностью; обрезанный вывод дочитывай
отдельными запросами. Составь перечень применимых требований и проверь по нему
весь diff перед завершением. Существующий код служит примером только там, где
не противоречит нормативным правилам.
